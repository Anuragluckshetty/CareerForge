# API documentation

The canonical interactive API documentation is generated by FastAPI at
`http://localhost:8000/docs` while the backend is running.

## Core endpoints

### `GET /health`

Returns a small process-readiness response:

```json
{
  "status": "ok",
  "service": "CareerForge API"
}
```

Additional endpoints include:

- `GET /api/v1/agents`
- `POST /api/v1/practice/ask`
- `POST /api/v1/assistant/chat`
- `POST /api/v1/assistant/resume/upload`
- `POST /api/v1/assistant/resume/chat`
- `POST /api/v1/assistant/resume/generate`
- `POST /api/v1/auth/register`
- `POST /api/v1/auth/login`
- `GET /api/v1/auth/me`
- `PUT /api/v1/auth/profile`

Registration and login return a bearer access token. Send it as
`Authorization: Bearer <access_token>` to `/api/v1/auth/me` and
`/api/v1/auth/profile`.

The React client routes authenticated users to `/overview`, `/practice`,
`/mock-interviews`, `/resume-review`, and `/progress`. `/login` and `/register`
are the public authentication pages. The frontend restores a saved session by
validating its token with `/api/v1/auth/me`.

### Generate a tailored resume

`POST /api/v1/assistant/resume/generate` accepts JSON containing `resume_text`
(20–40,000 characters) and `target_job_role`. It returns validated structured
resume fields and `latex_source`, a complete escaped LaTeX document. The
frontend uses those same structured fields for the preview and PDF download.
Sections without supported source details are left empty.

```json
{
  "resume_text": "Candidate-provided resume text...",
  "target_job_role": "Software Engineer"
}
```
